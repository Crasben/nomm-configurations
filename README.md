# NOMM Configurations repo

This is a repo that stores the game configurations built by the community for the NOMM app.

At every startup of the NOMM app (after version 0.13.0), this repo will be used to update the configurations on the NOMM app.

## Contributing

Contributing is super simple!

### Creating your configuration file

First, use the inbuilt game configuration builder by clicking this button on NOMM (version 0.13.0+)
<img width="1031" height="789" alt="image" src="https://github.com/user-attachments/assets/d059c602-1aab-4942-9a1f-8279349efd94" />

Then follow the instructions to create your configuration.

### Finding your created configuration file

Once your configuration is created, you can go find it by going in the settings of NOMM and then opening the configuration folder:

<img width="737" height="221" alt="image" src="https://github.com/user-attachments/assets/689619f8-4ad7-4266-8781-4c96548b0e41" />

Then open the `custom_game_configs` folder and you will find your created configurations!

### Sharing your creation with the community

Now comes the slightly harder part...
1. Make sure you have a Github account.
2. Log in!
3. Fork the repository
<img width="1725" height="604" alt="image" src="https://github.com/user-attachments/assets/7c016bfa-3f38-438a-ad33-acdffb652c40" />

4. Keep everything default and click the green `Create fork` button
5. You will now be on your own version of the repository
6. Click the <img width="80" height="20" alt="image" src="https://github.com/user-attachments/assets/c20dfa6d-5c44-4c93-bd79-404ce264a561" />
 button
7. Select `Upload files`
8. Select all your .yaml configurations that you have created and you wish to upload
9. Click on the green `Commit changes` button
10. Click the <img width="102" height="25" alt="image" src="https://github.com/user-attachments/assets/e20321c0-09fe-4bc0-9bd1-54c69465aaac" /> button
11. Click `Open pull request`
12. Give your pull request a name & description (for now we don't have any standards/templates but this might change in the future)
13. Click `Create pull request`

### And you're done!
